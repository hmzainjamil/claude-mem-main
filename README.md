# Claude-Mem source mirror

This repository contains a nested copy of the upstream [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) project under [claude-mem-main/](claude-mem-main/). The nested project identifies its upstream author, repository, version, and AGPL-3.0 license in its package and plugin manifests.

This outer repository is not itself the package root. Do not run installation, build, or test commands from this directory. Start with [the nested project README](claude-mem-main/README.md) and check its package manifest and license for current instructions.

## Relationship and freshness

The nested copy identifies a specific source snapshot. This README does not establish whether or how it is synchronized with upstream. Compare commits and review differences against upstream before relying on the copy or submitting changes.

For current releases, supported integrations, data behavior, privacy controls, dependencies, and setup instructions, use the upstream project documentation. Those details change over time.
